key findings

GPU Speedup Depends on Image Size (Measured on GCP Tesla T4) On small images (512×512), the T4 GPU is 30× slower than serial CPU (0.123s vs 0.004s) — kernel launch and H2D/D2H memory transfer overhead dominates when there are few pixels to compute. On large images (4000×4000), the GPU delivers an 11.19× speedup (0.039s vs 0.441s) once that fixed overhead is amortized across 16 million pixels.
OpenMP Oversubscription on Cloud VMs (Confirmed on Colab) Colab VMs have 2 real vCPUs. With 2 OpenMP threads: 1.12× speedup over serial. With 4 threads on 2 vCPUs: 0.91× — slower than serial on small images. On large images, 4 threads slightly edged out 2 threads (4.22 vs 3.94 img/s) because compute time outweighed scheduling overhead — but efficiency remained low. This directly proves parallel performance depends on real available hardware.
Cloud GPU (GCP Tesla T4) — Real Measured Results Platform: Google Colab (GCP), GPU: Tesla T4 15 GB, Driver 580.82.
Large image speedup: 11.19× vs serial CPU on the same cloud VM. Cloud GPU access removes the need to own dedicated hardware — a core cloud computing benefit. The GPU Dockerfile is ready to deploy this as a live cloud GPU web service.
