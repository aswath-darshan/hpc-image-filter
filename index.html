Unit 1 • Baseline

Serial C Engine

Sequential single-core execution compiled with -O2 optimization. Strictly sequential pixel traversal serving as the baseline (S = 1.00×).

serial_filter.c
Unit 2 • Multi-Core

OpenMP Parallelism

Shared-memory fork-join multithreading. Embarrassingly parallel pixel decomposition across CPU cores with dynamic loop scheduling.

openmp_filter.c
Unit 3 • Massive GPU

CUDA Mass Parallel

Discrete GPU kernel. 2D grid of 16×16 thread blocks mapping millions of threads onto 40 Streaming Multiprocessors (SMs).

cuda_filter.cu

CUDA Streams & DMA

Speedup & Parallel Efficiency Master Evaluation
Amdahl's Law & Architecture Metrics
Speedup Formulation
S = Tserial / Tparallel
Ratio of sequential baseline execution time to parallel execution time. S > 1 indicates parallel speedup.
CPU Parallel Efficiency
E = S / P × 100%
P = physical thread/core count. E = 100% represents theoretical ideal linear scalability without parallel overhead.
GPU SM Efficiency
E = S / SMcount × 100%
P = Streaming Multiprocessors (SMs). High speedup with low %-per-SM is expected due to massive SIMT design.
